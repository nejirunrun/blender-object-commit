# blender-object-commit

Blender のオブジェクト単位で git 風のコミットを行う拡張 (Extension) です。
オブジェクトの状態を記録し、履歴をビューポートで見比べ、任意の時点へ戻せます。
履歴はすべて `.blend` ファイルの中に保存され、外部ファイルは作りません。

対象: Blender 5.0 以降 (動作確認は 5.2.2)。

**試作段階です。** 自己責任でお使いください。ファイルのバックアップを取ったうえで
使用し、データの損失・破損について作者は責任を負いません。

## インストール

[Releases](https://github.com/nejirunrun/blender-object-commit/releases) から
zip をダウンロードし、Preferences > Get Extensions > Install from Disk で入れてください。

## 使い方

サイドバー (`N`) の **Commits** タブ。オブジェクトをアクティブにして操作します。

| 操作 | 内容 |
|---|---|
| コミット (`+`) | メッセージ付きで現在の状態を記録し、HEAD を進める |
| リストで選択 | 閲覧モード。作業中のオブジェクトの代わりにそのコミットをビューポートに表示する。ビューポートをクリックするか `Esc` で戻る |
| チェックアウト (`✔`) | 選択中のコミットでオブジェクトを上書きする。作業状態が HEAD と違えば先に自動スタッシュする。1 回の undo で戻せる |
| スタッシュ / ポップ | HEAD を動かさずに作業状態を保存する / 最新のスタッシュを復元して消す |
| 削除 | 選択中のコミットを消す。後続のコミットはその親につながる |
| HEAD との差分 | 作業中のオブジェクトと HEAD の違いを要約する |
| 検証 | 全コミットの形状データを記録時のハッシュと照合する |

選択中のコミットについて、親コミットからの変更 (頂点・辺・面数、属性、モディファイア、
コンストレイント、トランスフォーム、マテリアルスロット) の要約も表示します。

## コミットに含まれるもの

**オブジェクトデータ** (メッシュ・カーブ・ランプ等) はデータブロックごと複製するので、
その中身は全部入ります: 頂点・UV・属性 (頂点カラー含む)・頂点グループとウェイト・
シェイプキー・カスタム法線・スカルプトマスクなど。

**オブジェクト側** は項目を指定して保存しています:

- トランスフォーム (delta 含む)、親子関係 (ボーン親・parent inverse 含む)
- モディファイアとコンストレイントのスタック。設定値と参照先 (名前)、
  カーブ型の設定 (Bevel の Custom Profile、Warp / Hook の Falloff Curve、Vertex Weight 系の Map Curve)
- マテリアルスロットの割当
- 表示設定 (表示方法、ワイヤ、名前、軸、バウンド、Empty の表示、シェイプキー表示)
- 可視性 (ビューポート / レンダー / 選択、レイ可視性、holdout、shadow catcher、pass index)
- インスタンス設定 (頂点 / 面 / コレクション)
- コリジョン設定、ラインアート設定
- カスタムプロパティ

**含まれないもの** (チェックアウトしても戻りません):

- 共有データブロックの中身: マテリアル、ノードツリー、テクスチャ、アクション、
  アーマチュアのポーズ。参照 (どれを使うか) は戻ります
- アニメーションキー、ドライバ
- オペレーターでしか作れない物理設定: Force Field、Rigid Body、Soft Body、Cloth、
  パーティクルシステム
- コレクションへの所属、選択状態、編集モードの状態
- Grease Pencil オブジェクト

リンク / ライブラリオーバーライドのオブジェクトはコミットできますがチェックアウトはできません。

## 保存方式

履歴はオブジェクト自身 (`Object.ocv`) に付くので、保存や複製に追従します。
形状は `.ocv_<uuid>_<n>` という名前の隠しデータブロック (fake user 付き)、
メタデータは JSON 文字列です。コミットごとに完全な複製を持つため、頂点数の多い
メッシュで履歴を重ねるとファイルが大きくなります。合計はパネルに表示されます。

## 開発

```bash
blender -b --factory-startup --python tests/smoke.py
```

コミット / チェックアウト / 閲覧 / スタッシュ / 検証 / 削除と、保存→再読込を
ヘッドレスで一通り実行し、成功すれば `OK` を表示します。
